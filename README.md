# Fitness Tracker

## Overview
The **Fitness Tracker** is a Python-based application that helps users monitor their health and fitness. It provides functionalities to check weight, calculate BMI, and includes four additional features to assist users in tracking their fitness progress effectively.

## Features
- ✅ **Weight Tracking**: Input your weight and track changes over time.
- ✅ **BMI Calculator**: Automatically calculate Body Mass Index (BMI) based on height and weight.
- ✅ **Additional Functions**:
  1. **Calorie Intake Estimator**: Estimate daily caloric needs based on activity level.
  2. **Water Intake Reminder**: Get recommended daily water intake.
  3. **Step Counter Goal**: Set and track daily step goals.
  4. **Exercise Recommendation**: Get personalized workout suggestions based on BMI.

## Installation
### Prerequisites
Ensure you have Python installed on your system. You can download it from [Python's official website](https://www.python.org/downloads/).

### Steps
1. Clone this repository:
   ```bash
   git clone https://github.com/MuhammadAsimKundi/fitness-tracker.git
   cd fitness-tracker
   ```
2. Install required dependencies (if any):
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application:
   ```bash
   python fitness_tracker.py
   ```

## Usage
1. Run the program in the terminal.
2. Follow the on-screen instructions to input your details.
3. View results and recommendations for improving fitness.
